# P6a 前端配合清单（学生对导师评价）

> 后端已全部实现并通过编译验证。本文档面向前端，按角色列出需要新增的页面/模块、
> 接口出入参字段表与交互约定。**先部署后端（执行 P6 SQL → 打包新 jar），再联调前端。**
>
> 定位说明：导师评价是「软提醒」——终期答辩通过后邀请学生评价，**不卡定稿/归档阶段门**；
> 评价结果仅作教师考核数据源，不进学生成绩合成。

## 0. 上线依赖

| 顺序 | 动作 | 说明 |
|---|---|---|
| 1 | 执行 `src/main/resources/db/补论文全生命周期P6.sql` | 幂等可重复；漏跑则新接口全站 500 |
| 2 | 打包部署新 jar | `mvn clean package` |
| 3 | （可选）yml 配置 `admin.advisor-eval.window-days` | 评价窗口天数，默认 30（答辩通过后 N 天内可评） |
| 4 | 前端构建部署 | 本清单对应改造 |

## 1. 全局约定

### 1.1 新增业务错误码

| errorCode | HTTP | 含义 | 前端处理建议 |
|---|---|---|---|
| 40917 | 409 | 论文尚未通过终期答辩（或未分配导师），暂不可评价 | message 展示，置灰评价入口 |
| 40918 | 409 | 已提交过导师评价，请勿重复提交 | message 展示，切换为已提交回显态 |
| 40919 | 409 | 导师评价窗口已关闭（答辩通过超过 window-days 天） | message 展示，置灰评价入口 |

### 1.2 新增通知类型（NoticeType 枚举，消息中心需能渲染）

| type | 标题 | 默认内容 |
|---|---|---|
| ADVISOR_EVAL_INVITE | 导师评价邀请 | 您已通过终期答辩，欢迎对指导教师的指导工作作出评价 |

触发时机：终期答辩批次组长提交结论「通过」后由后端自动发送（只发一次，不催办）。

### 1.3 预设标签字典 advisor_eval_tag

提交与回显均用 dict_value；`/my` 接口已返回 `tagOptions`（label+value），**前端无需再查字典**。

| value | label | 倾向 |
|---|---|---|
| reply_timely | 回复及时 | 正向 |
| feedback_detailed | 反馈细致 | 正向 |
| strict_demanding | 要求严格 | 正向 |
| tailored_guidance | 因材施教 | 正向 |
| resource_support | 资源丰富 | 正向 |
| guidance_lacking | 指导偏少 | 负向 |
| feedback_slow | 反馈较慢 | 负向 |

### 1.4 通用注意

- 雪花 ID（paperId/评价 id/teacherId/studentId/collegeId）一律按**字符串**接收与回传
- 统一返回体：`{ code, errorCode, message, data }`，code=200 成功；40917~40919 时 code=409
- 评分统一 1-5 星整数；导师评价分（百分制）后端已算好，前端直接展示

## 2. 学生端

### 2.1 新页：导师评价（表单 + 状态回显一体）

**入口建议：** 收到 ADVISOR_EVAL_INVITE 通知后跳转；论文状态为「答辩已通过/已定稿」时在论文详情页提供「评价导师」按钮。进入页面先查状态接口决定渲染表单还是回显。

**查询评价状态：**

```
GET /check/api/student/advisor-evaluation/my?paperId=
权限：STUDENT（仅本人论文；paperId 可空，空则取本人最新一篇论文）
```

**响应 data（AdvisorEvalStatusVO）：**

| 字段 | 类型 | 说明 |
|---|---|---|
| paperId | string \| null | 论文ID（学生无论文时为 null） |
| paperTitle | string | 论文标题 |
| teacherName | string \| null | 指导教师姓名（未分配导师为 null） |
| evaluable | boolean | 当前是否可提交评价 |
| reason | string \| null | 不可评原因（evaluable=false 时非空，直接展示） |
| windowEndTime | string \| null | 评价窗口截止时间 `yyyy-MM-dd HH:mm:ss`（null=不限窗口，存量论文） |
| submitted | boolean | 是否已提交 |
| scoreTimeliness | number \| null | 指导及时性（已提交时回显） |
| scoreQuality | number \| null | 反馈质量 |
| scoreAttitude | number \| null | 责任心态度 |
| scoreProfessional | number \| null | 专业能力 |
| scoreOverall | number \| null | 总体满意度 |
| tags | string[] | 已选标签 dict_value 列表（未提交为空数组） |
| comment | string \| null | 文字评语 |
| submitTime | string \| null | 提交时间 |
| tagOptions | {label, value}[] | 可选标签（恒返回，渲染多选框） |

**提交评价：**

```
POST /check/api/student/advisor-evaluation
权限：STUDENT（仅论文学生本人）
Content-Type: application/json
```

**请求体（AdvisorEvalSubmitReq）：**

| 字段 | 类型 | 必填 | 校验 | 说明 |
|---|---|---|---|---|
| paperId | string | 是 | | 论文ID |
| scoreTimeliness | number | 是 | 1-5 | 指导及时性 |
| scoreQuality | number | 是 | 1-5 | 反馈质量 |
| scoreAttitude | number | 是 | 1-5 | 责任心态度 |
| scoreProfessional | number | 是 | 1-5 | 专业能力 |
| scoreOverall | number | 是 | 1-5 | 总体满意度 |
| tags | string[] | 否 | ≤7 个，须为 dict_value 白名单 | 预设标签（非法值返回 40004） |
| comment | string | 否 | ≤500 字符 | 文字评语（后端纯文本清洗） |

**页面状态机（按 evaluable/submitted 渲染）：**

| submitted | evaluable | 渲染 |
|---|---|---|
| false | true | 评价表单（5 个星级 + 标签多选 + 评语 + 提交按钮）；windowEndTime 非 null 时显示「请于 x 前完成评价」 |
| false | false | 不可评提示卡（reason 原文，如「论文尚未通过终期答辩，暂不可评价」） |
| true | false | 已提交回显（星级只读 + 标签 label 展示 + 评语 + 提交时间），**不提供修改入口**（提交后不可改） |

> 标签回显时 value → label 翻译用 tagOptions 映射；提交成功后建议重新拉一次 /my 切到回显态。

## 3. 教师端

### 3.1 新页/模块：学生评价汇总（仅聚合，匿名保护）

```
GET /check/api/teacher/advisor-evaluation/summary
权限：TEACHER
```

**响应 data（AdvisorEvalSummaryVO）：**

| 字段 | 类型 | 说明 |
|---|---|---|
| masked | boolean | true=样本不足（<3 份），分数与标签全部为 null/空 |
| evalCount | number | 已收到评价份数（份数不敏感，掩码时也返回） |
| avgTimeliness | number \| null | 指导及时性均分（1-5，两位小数） |
| avgQuality | number \| null | 反馈质量均分 |
| avgAttitude | number \| null | 责任心态度均分 |
| avgProfessional | number \| null | 专业能力均分 |
| avgOverall | number \| null | 总体满意度均分 |
| advisorScore | number \| null | 导师评价分（百分制 = avgOverall×20，一位小数） |
| tagStats | {tag, label, count}[] | 标签频次（按次数降序；掩码时为空数组） |

**页面布局建议：**

1. masked=true：整卡显示「样本不足，暂不展示（已收到 N 份评价）」，**不要显示任何分数**——小样本可被导师对照时间线反推学生身份，掩码是刻意的匿名保护
2. masked=false：五维雷达图/条形图 + advisorScore 大字卡 + 标签词云或频次条（label 已由后端翻译好）
3. 教师端**永远没有**单条评价明细与评语查询入口（后端不提供，属设计而非缺漏）

## 4. 管理端（ADMIN）

### 4.1 新页：导师评价管理（实名分页 + 统计 + 导出）

**评价实名分页：**

```
GET /check/api/admin/advisor-evaluation/page?pageNum=1&pageSize=10&teacherId=&collegeId=&minOverall=&maxOverall=
权限：ADMIN
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum | number | 是 | 页码，从 1 开始（缺省 1，但**建议显式传**，项目既往踩坑） |
| pageSize | number | 是 | 每页条数（≤100，缺省 10） |
| teacherId | string | 否 | 按导师过滤 |
| collegeId | string | 否 | 按论文学院过滤 |
| minOverall / maxOverall | number | 否 | 总体满意度分数段（1-5） |

**响应：** MyBatis-Plus `Page<AdvisorEvalPageItemVO>`（`records/total/size/current` 结构），按提交时间倒序。

**AdvisorEvalPageItemVO：**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 评价ID |
| paperId / paperTitle | string | 论文 |
| studentId / studentName | string | 学生（**实名**，仅管理端可见，用于防滥用追溯，请勿外泄展示） |
| teacherId / teacherName | string | 导师 |
| collegeId / collegeName | string \| null | 学院（collegeId 为 null 表示未分配） |
| scoreTimeliness / scoreQuality / scoreAttitude / scoreProfessional / scoreOverall | number | 五维评分 |
| tags | string[] | 标签 dict_value 列表（前端按 1.3 字典翻译，未知值显示原文） |
| comment | string \| null | 评语 |
| createTime | string | 提交时间 `yyyy-MM-dd HH:mm:ss` |

**评价统计：**

```
GET /check/api/admin/advisor-evaluation/stats
权限：ADMIN
```

**响应 data（AdvisorEvalStatsVO）：**

| 字段 | 类型 | 说明 |
|---|---|---|
| eligiblePapers | number | 可评论文数（答辩通过/已定稿且已分配导师） |
| totalEvaluations | number | 已提交评价份数 |
| completionRate | number | 完成率（百分比两位小数，如 45.32；eligible=0 时为 0） |
| teacherRank | TeacherRankItem[] | 导师排行（按评价分降序） |
| collegeCompare | CollegeCompareItem[] | 学院对比（按均分降序） |
| lowScoreTeachers | TeacherRankItem[] | 低分预警名单（teacherRank 的子集） |

**TeacherRankItem：**

| 字段 | 类型 | 说明 |
|---|---|---|
| teacherId / teacherName | string | 导师 |
| evalCount | number | 评价份数 |
| avgOverall | number | 总体均分（两位小数） |
| advisorScore | number \| null | 导师评价分（百分制一位小数） |
| lowScore | boolean | 低分预警标记（evalCount≥3 且 avgOverall<3.0） |

**CollegeCompareItem：**

| 字段 | 类型 | 说明 |
|---|---|---|
| collegeId | string \| null | 学院ID（null 行 collegeName=「未分配」） |
| collegeName | string | 学院名（college 记录缺失时为「未知学院」） |
| evalCount | number | 评价份数 |
| avgOverall | number | 总体均分（两位小数） |

**导出：**

```
GET /check/api/admin/advisor-evaluation/export
权限：ADMIN（浏览器直接下载 xlsx，单 sheet「导师评价明细」）
```

**布局建议：**

1. 顶部统计卡：完成率（eligiblePapers/totalEvaluations + completionRate 进度环）+ 低分预警数
2. 导师排行表：advisorScore 排序列 + lowScore=true 行红色标记/预警图标；行内可联动右侧「该导师评价明细」（用 page 接口传 teacherId）
3. 学院对比横向条形图
4. 低分预警名单单独卡片置顶展示（面向教学督导场景）
5. 明细分页表：五维评分列 + 标签（翻译为中文顿号拼接）+ 评语展开 + 筛选器（导师/学院/分数段）

## 5. 联调注意事项

1. **教师端掩码是铁律**：masked=true 时分数与 tagStats 为 null/空属正常，不是接口异常；任何情况下教师端都不要尝试展示单条评价
2. **评价提交后不可改**：表单提交前给二次确认弹窗（「提交后不可修改」）
3. **窗口期展示**：windowEndTime 为 null 表示存量论文不限窗口，不要显示「已截止」
4. **存量论文可补评**：P6 上线前已 defense_passed/finalized 的论文同样可评（无状态日志者不限窗口），学生列表入口按 /my 返回的 evaluable 决定显隐
5. **雪花 ID 字符串化**：所有 19 位 ID 按字符串处理
6. **page 接口显式传分页参数**：pageNum/pageSize 虽有默认值，沿用项目惯例显式传参
7. **标签翻译兜底**：tagStats/排行中的 label 已由后端翻译；明细行 tags 为 dict_value 数组，前端按 1.3 表翻译，遇到未知值（字典被删的历史数据）直接显示原文
